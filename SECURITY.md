# Security

Please report a vulnerability in Patchhound privately, through GitHub: [Report a vulnerability](https://github.com/CodeGeek04/patchhound/security/advisories/new). Do not open a public issue for it.

Say what is affected (the CLI, `patchhound init`, or the GitHub Action and the workflow it runs), how to reproduce it, and what an attacker could do with it. You will get an answer within a few days.

How Patchhound keeps secrets and write access apart, and what it will not do, is in [docs/github-action.md](docs/github-action.md).
